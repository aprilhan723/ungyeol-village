# 운결마을 · Ungyeol Village 2

[공개 마을 열기](https://ungyeol-village.vercel.app) · [관계 지도](https://ungyeol-village.vercel.app/?view=map)

**우리의 인연이 사는 곳.** 제공된 열두 명의 간지 명식을 모티프로 만든 3D 이야기 마을입니다. 로그인 없이 탐험하고, 주민을 선택하고, 66쌍의 관계 근거를 읽을 수 있습니다.

## 주요 기능

- 캐릭터로 플레이하는 3D 마을: 땅 클릭, WASD·방향키 이동, 카메라 회전/확대/따라가기/전체 보기
- 주민이 스스로 걷고 서로 찾아가는 자율 시뮬레이션: 경로 탐색으로 연못과 장애물을 우회
- 실제 만난 위치에서 하트·번개·선물·공명 효과와 두 사람의 말풍선 발생
- 다가가서 인사, 선물, 함께 춤추기, 주민 전원 마을 축제
- 열두 주민 모두 새로 제작한 정령 디자인: 물결 망토, 촛농 몸, 태양 갈기, 산 골렘, 나무 정령, 금속 기사, 수정 요정, 화분 정령, 물방울과 시냇물 꼬리
- 관절이 있는 팔·다리의 걷기, 인사, 춤 애니메이션. 도감 초상은 같은 3D 모델에서 렌더링
- 햇살/달빛, 창문 조명과 반딧불, 일시정지, 산책 속도 1×/2×
- 현재 기기에 저장되는 발견한 인연과 게임 친밀도. 퀘스트는 이번 산책 기준
- 보조 화면: 66쌍 명식 관계 지도/근거, 랭킹, 주민 도감, 입력 검증과 JSON 마을 이동

관계 점수는 첫 만남의 연출과 NPC 상대 선택에 쓰입니다. ‘함께한 마음’은 대화(+2~5), 선물(+8), 춤(+6)으로 증가하는 게임 데이터이며 사주 점수와 구분합니다. 플레이어가 일시정지하거나 창을 떠난 시간은 시뮬레이션이 따라잡아 가속하지 않습니다.

## 실행

Node.js 22.12 이상 (또는 지원되는 최신 LTS)을 사용하세요.

```sh
npm ci
npm run dev
npm test
npm run build
```

브라우저 검증:

```sh
npx playwright install chromium
npm run dev
# 다른 터미널
npm run test:e2e
```

기존 Chromium을 사용하려면 `CHROMIUM_PATH` 환경 변수에 실행 파일 경로를 지정하세요. 배포 환경 검증은 `BASE_URL`로 지정합니다.

## 해석 범위

전통 규칙과 창작 서사를 명확히 구분합니다. 이 서비스는 명리 상징을 활용한 게임이며 완전한 명리 감정 도구가 아닙니다. 실제 사랑·짝사랑·악연·인품·미래는 판정하지 않습니다.

입력 간지 음양, 연간에 따른 월간, 일간에 따른 시간을 검증합니다. 출생 날짜·장소를 받지 않았으므로 만세력 역산이나 진태양시 보정은 하지 않습니다. 시주가 없는 8명은 시주를 추정하지 않습니다.

사용 규칙: 일간 오행과 음양, 월지 계절, 지장간 표, 일간 간 십신, 천간 오합, 지지 육합·충, 일간 기준 천을귀인 보조표. 오행 막대는 알려진 천간과 지지 대표 오행의 **단순 개수**이며 세력·용신 분석이 아닙니다. 월령에 따른 세력, 조후, 격국, 합화 성립, 형파해 종합, 대운·세운은 계산하지 않습니다.

### 공개 창작 점수

- 끌림: 기본 30 + 일간합 24 + 일지육합 20 + 그 외 지지육합 쌍당 4 + 동일 일간 오행 10 + 일간 상생 8
- 긴장: 일지충 30 + 그 외 지지충 쌍당 6
- 도움: 일간 상생 20 + 방향별 천을귀인 표 해당 12
- 각각 99 상한. 그 외 지지 비교에서는 일지끼리 비교를 제외하고, 같은 종류의 쌍은 한 번만 계산합니다.
- 유형 우선순위: 끌림≥58 & 긴장≥18 → 불꽃 케미; 끌림≥58 → 끌림의 인연; 도움≥24 → 귀인 동행; 긴장≥24 → 티격태격; 동일 오행 → 닮은 영혼; 나머지 → 느긋한 이웃.

가중치와 서사 유형은 제품을 위한 창작 규칙입니다. 전통 명리의 표준 궁합 점수나 검증된 확률이 아닙니다. 알려진 글자 수 차이에 따른 순위 비교의 한계가 있습니다. 상세 화면에서 적용 근거를 모두 읽을 수 있습니다.

공개 고전 참고 자료:

- [적천수 · 천간론](https://zh.wikisource.org/zh/滴天髓/02)
- [삼명통회 사고전서본](<https://zh.wikisource.org/wiki/三命通會_(四庫全書本)/全覽>)

천간의 자연 비유를 디자인 언어로 사용합니다. 고전의 모든 해석을 구현했다고 주장하지 않습니다.

## 저장과 확장

원본 12명의 마을은 배포 소스에 포함됩니다. 웹에서 추가한 주민은 **현재 기기의 localStorage**에 저장됩니다. 공유 링크는 공개 원본 마을의 화면과 선택 주민을 공유하며, 로컬에서 추가한 데이터는 자동으로 전송되지 않습니다. 추가 주민은 JSON 파일로 내보내 다른 기기에서 불러올 수 있습니다. 가져오거나 초기화하기 전 현재 마을을 자동 다운로드하여 보관합니다. 다운로드를 브라우저가 차단하는 환경에서는 수동으로 내보내 보관하세요.

JSON은 `{version:1,name,people:[...]}`입니다. 모든 주민은 고유한 `id`, `name`, `pillars:[년주,월주,일주,시주 또는 null]`을 갖습니다. 파일 크기, 개수, 간지, 식별자와 스타일 색을 검증하고 표시 문자열을 이스케이프합니다.

추후 공용 마을 생성과 영구 링크가 필요하면 이 데이터 경계에 저장 API를 붙일 수 있습니다. 현재는 서버 DB·사용자 계정·공유 쓰기 권한을 요구하지 않는 정적 앱입니다. 새로운 테마는 `world.js`의 재질·건축물 레이어를, 감수된 명리 규칙은 `engine.js`를 독립적으로 확장할 수 있습니다.

## 배포

Vercel에 Vite 프로젝트로 연결하면 `npm run build` 결과인 `dist`를 배포합니다. 환경 변수나 API 키는 필요 없습니다. `vercel.json`에 설정을 포함했습니다.
